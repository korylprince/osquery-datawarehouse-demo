# dwh-chat

Interactive chat interface for querying and analyzing data in a Trino data warehouse. Built on Chainlit, it connects to an MCP server that provides SQL execution, a Python sandbox, and chart generation - all driven by any OpenAI-compatible LLM.

## Features

- Natural-language queries against Trino (SQL auto-generated by the LLM)
- Inline chart rendering (matplotlib/seaborn via sandboxed Python)
- Per-conversation model selection via chat profiles
- Persistent conversation history (PostgreSQL)
- Single anonymous user (no auth)

## Configuration

### Environment Variables

| Variable | Required | Default | Description |
|---|---|---|---|
| `DB_HOST` | Yes | - | PostgreSQL hostname |
| `DB_USER` | Yes | - | PostgreSQL username |
| `DB_PASSWORD` | Yes | - | PostgreSQL password |
| `DB_NAME` | Yes | - | PostgreSQL database name |
| `MCP_URL` | No | `http://data-warehouse-mcp.data-warehouse-mcp.svc.cluster.local:8080/mcp` | MCP server endpoint |
| `ENDPOINTS_CONFIG` | No | `/config/endpoints.yaml` | Path to the LLM endpoints YAML |

### LLM Endpoints (`endpoints.yaml`)

A YAML list mounted at the path specified by `ENDPOINTS_CONFIG`. Each entry defines one or more models available in the chat profile picker:

```yaml
- name: "Local"
  baseUrl: "http://model-router.model-api-operator.svc.cluster.local:8080"
  models:
    - "my-model"
- name: "OpenAI"
  baseUrl: "https://api.openai.com"
  models:
    - "gpt-4o"
  apiKeyFile: "/secrets/openai-api-key"
```

| Field | Required | Description |
|---|---|---|
| `name` | Yes | Display name in the profile picker |
| `baseUrl` | Yes | OpenAI-compatible base URL (no trailing slash) |
| `models` | Yes | List of model IDs (strings or objects with `id` and optional `thinking: true`) |
| `apiKeyFile` | No | Path to a file containing the API key |
